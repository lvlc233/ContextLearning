# 评估与学习信号

## 本章定位

本章负责说明训练如何获得判断依据。

## 本章要解决的问题

普通输出如何变成可用于训练的信号？

## 本章引出的概念

- 信息
- 信号
- 学习信号
- 偏离信号
- 奖励信号
- 评估
- 数据标注

## 什么是学习信号

`学习信号` 指的是：在上下文训练过程中产生的、用于判断上下文是否正在逼近训练目标的信息。

在早期文档或流程语境中，它也可能被称为 `训练信号`、`训练反馈信号` 或 `反馈信号`。本文后续统一使用 `学习信号`。

学习信号可以来自人类反馈、样本表现、失败案例、数据标注、版本对比或测试结果。


## 与训练目标和优化方向的关系

如果说 `训练目标` 回答的是：

```text
我希望上下文最终逼近什么行为、状态或效果？
```

`优化方向` 回答的是：

```text
下一步应该往哪里调整？
```

那么 `学习信号` 回答的是：

```text
当前这次输出、修改或测试结果，实际提供了什么判断依据？
```

三者之间的关系可以理解为：

```text
训练目标：期望逼近的行为、状态或效果。
学习信号：运行过程中观察到的判断依据。
优化方向：基于学习信号形成的调整方向。
```

学习信号通常需要被进一步整理为评估结论、优化方向、判断标准或上下文修改依据，而不是直接作为上下文本体的一部分。

## 数据标注如何产生学习信号

`数据标注` 是产生 `学习信号` 的一种常见方式。

标注本身不是训练目标，也不是上下文本体。它的作用是把判断、理由和偏好记录下来，供后续整理成学习信号、判断标准或上下文修改依据。

人类偏好也可以通过数据标注表达。它可以表现为对某个输出的直接评价，也可以表现为对两个版本的比较，或者对某种规则方向的接受与拒绝。

例如，一条标注如果明确指出：

```text
压缩有效，但不能接受，因为它删除了失败条件和测试标准。
```

这条标注就不只是“好/坏”的结论，它还提供了偏离证据：删除失败条件和测试标准会让结果偏离训练目标。

这类判断可以进一步整理为学习信号：

```text
压缩上下文时，删除失败条件、任务边界或测试标准是负向信号。
```

也就是说，标注不是直接等于规则，而是为后续评估、信号整理和上下文调整提供依据。

## 偏离信号

`偏离信号` 是学习信号的一种，指当前状态与训练目标之间出现差距时，被观察到的具体证据。

偏离信号的重点不是笼统地说“输出不好”，而是要指出：

- 偏离了哪个训练目标。
- 偏离发生在什么输出位置或行为上。
- 偏离是否稳定出现。
- 偏离是否足以触发上下文修改。

例如：

```text
训练目标：
压缩上下文时，保留任务边界、失败条件和测试标准。

模型输出：
新版本上下文更短，但删除了失败条件。

偏离信号：
压缩行为达成，但关键约束丢失。
```

这里的偏离信号不是“压缩得不好”这样一个笼统评价，而是指出当前结果相对于训练目标的具体差距。

## 奖励信号

`奖励信号` 是学习信号的一种，表示当前状态、输出或行为值得被强化。

在上下文学习中，奖励信号可以来自人类偏好、正向标注、版本比较中的“更好”判断，或者测试结果中的稳定改善。

例如：

```text
这一版代码评审先指出了具体风险，比上一版更符合训练目标。
```

这类判断说明当前上下文中的某些内容正在诱发更接近目标的 Agent 行为，因此可以作为后续保留、强化或继续扩展的依据。

## 边界

学习信号不是案例堆积。

学习信号也不是把人类反馈逐字写入上下文。

一个学习信号是否有效，关键不在于它是否来自真实案例，而在于它是否能帮助判断上下文正在接近目标还是偏离目标。
