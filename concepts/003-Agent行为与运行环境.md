# Agent 行为与运行环境

## 从同一份上下文的不同表现开始

假设你训练了一份 code review skill。它要求 Agent 在评审代码时不要泛泛而谈，而是先定位具体文件，再指出可以验证的风险。

第一次运行时，Agent 是这样做的：

```text
先查看登录相关文件。
调用工具：读取 src/auth/login.ts。
定位到 redirect_url 参与跳转的位置。
判断这里缺少白名单校验，存在开放重定向风险。
建议增加允许域名列表，并补充对应测试。
```

后来你把同一份 skill 换到另一个 Agent 上运行，它却只输出：

```text
整体看起来没有明显问题，建议补充测试。
```

这时你可能会想：是不是 skill 写得不够清楚？是不是应该再补一条“必须指出具体风险”的规则？

于是你开始修改 skill。你补了一条更强的规则：

```text
评审代码时，必须先读取相关文件，并指出具体风险。
```

重新运行后，结果还是没有变化。后来你才发现，第二个 Agent 根本没有仓库读取权限。它不是不想读取文件，而是不能读取文件。

于是你给它补上读取权限，再运行一次。这次它终于能打开文件了，但仍然没有指出具体风险，只是复述了几句代码结构。

后来你换了个能力更强的模型。结果它确实指出了风险，但也开始主动检查很多无关文件，输出变得很长，甚至把一些低风险问题说得很严重。

这时问题就变得复杂了：同一份 skill 的表现变化，并不只来自 skill 本身。工具权限、模型能力、运行引擎、任务输入，都会改变 Agent 最终表现出来的结果。

如果 Agent 行为完全不可观察、不可解释，训练就很难继续推进。因此，在讨论训练目标之前，需要先说明：什么是 Agent 行为，以及哪些信息会影响 Agent 行为。

## 什么是 Agent 行为

`Agent 行为` 指模型在指定运行环境中运行时表现出的动作集合。

它不只是某段中间输出的文本，也包括 Agent 在任务过程中如何理解任务、如何选择规划计划、如何调用工具、如何执行脚本，以及如何与用户交互等。

回到前面的 code review 例子，两次运行的差异并不只是“回答质量不同”。

第一次运行中，Agent 实际完成了一组动作：

```text
读取相关文件；
定位具体代码；
形成风险判断；
给出修改建议；
补充测试方向。
```

第二次运行中，Agent 表现出的动作则明显不同：

```text
没有读取文件；
没有定位代码；
没有形成具体风险判断；
只给出了泛泛建议。
```

这类差异，就是本文所说的 `Agent 行为` 差异。

因此，观察 Agent 行为时，不只看最终回答文本，还要看它在任务过程中做了什么：怎么读取信息、怎么调用工具、怎么拆解任务、怎么执行脚本、怎么追问用户、是否遵循上下文规则，以及是否把这些动作组织成有效的任务推进过程。

而这些动作信息，正是我们训练时最直接的训练依据。

也正因为如此，上下文训练不能只评估“输出好不好”，还要评估 Agent 在运行过程中表现出的动作价值。

## Agent 行为不是只由上下文决定

同一份上下文可能会引发不同 Agent 行为，是因为 Agent 行为不是只由上下文决定。

它通常受到多种条件共同影响：

```text
模型：使用的基础模型、推理能力、上下文长度、工具使用能力。
工具权限：是否能读写文件、访问网络、调用测试、使用 MCP 或 subagent。
执行环境：sandbox、harness、项目目录、可访问资源和权限边界。
任务输入：用户请求、样本内容、项目状态、已有上下文。
运行状态：已有会话历史、缓存状态、工具返回结果和中间产物。
运行引擎：Agent 如何计划、行动、观察、重试、回退或派遣 subagent。
```

其中，`运行环境` 更接近“Agent 在哪里运行”，例如 sandbox、工具权限、项目目录和可访问资源；`运行引擎` 更接近“Agent 如何推进任务”，例如 ReAct、loop、planner/executor、workflow 或 dynamic workflow。

因此，当 Agent 表现不符合预期时，问题不一定只来自上下文内容。它也可能来自模型能力不足、工具权限受限、运行环境缺失、任务输入不完整，或运行引擎没有给 Agent 使用这段上下文的机会。

## 这对上下文训练意味着什么

上下文训练依赖运行结果、评估和学习信号。但运行结果并不只由上下文决定。

这意味着，在分析一次训练结果时，需要区分：

```text
是上下文内容没有写清楚？
是模型能力不足以执行这条上下文？
是运行环境缺少必要工具或权限？
是任务输入没有提供足够信息？
是运行引擎没有给 Agent 使用这段上下文的机会？
```

如果不区分这些因素，训练过程就容易把环境问题误判为上下文问题，或者把模型偶然表现误判为上下文修改有效。

因此，Agent 行为与运行环境是观察训练结果时必须先确认的背景条件。只有先明确训练结果发生在哪里，后续才更容易讨论训练目标、学习信号和优化方向。
