# 训练目标

## 从修改上下文开始

在上下文工程中，最经常发生的事情很简单：你改了一段上下文。

看到输出不够具体，就补一条规则；发现某个案例失败，就把案例写进去；觉得回复太长，就删掉一些说明；换了一个 Agent 后表现变差，就再加一段适配要求。

这些修改都可能有用，也都是上下文工程中的常见操作。

但一次修改，很难说明太多东西。

补了一条“回答要更具体”的规则后，下一次输出确实更具体了，但也可能变得更啰嗦。

删掉一段长说明后，回复确实更短了，但也可能丢掉了原本必要的约束。

加入一个失败案例后，那个案例确实不再失败了，但也可能让上下文过度贴合这个案例。

换了一个 Agent 后补了一段适配要求，表现确实暂时恢复了，但也可能让这份上下文更难迁移到其他环境。

如果每次修改只是在回应眼前的问题，上下文很容易变成一组局部补丁：这次补了具体性，下次又破坏简洁性；这次增加工具调用，下次又带来无关检查；这次修复一个 Agent，换到另一个环境又失效。

因此，更关键的问题不是继续问“还要怎么改”，而是先问：这些修改背后，到底想让上下文变成什么样？

是想要它变成一份让 Agent 更少啰嗦的上下文，还是一份让 Agent 更会解释的上下文？它是更贴合当前 Agent，还是更容易迁移到其他环境？它是在补住某个失败案例，还是在形成更一般的判断能力？

当这种追问出现后，问题就不再只是一次上下文修改，而是正式进入了上下文训练领域。

## 什么是训练目标

在上下文学习中，`训练目标` 指的是通过上下文训练希望 Agent 系统能够达到的预期效果或目标状态。它可以是让 Agent 产生某种行为，也可以是保持已有能力不变、减少上下文长度、降低噪声、适配新环境，或在多个约束之间取得更稳定的平衡。

但请注意，文档中写下的目标语句，本身都是对训练目标的描述，而不是训练目标本身。训练目标是这些语句所指向的预期效果或目标状态；语言描述只是帮助我们记录、讨论和传递它的方式。

例如，“让代码评审更具体”只是一种较为粗略的描述。它实际可能指向风险定位、文件引用、行为影响、测试建议等不同效果。只有结合当前训练真正希望达到的行为状态，才能确认这句话具体指向什么。

训练目标也不是某一次表现出目标效果的理想输出。某次输出可以作为样本或参考，帮助人们观察和理解目标，但不能直接等同于训练目标本身。

训练目标对于整个上下文训练来说非常重要，没有训练目标，虽然仍然可以有“修改”“尝试”“观察”“比较”的动作，但很难称为训练。因为训练至少意味着：存在某个希望逼近的效果，并且后续变化可以围绕这个效果被判断。

同样是Agent的输出变短，如果训练目标是减少啰嗦，它可能是在接近目标；如果训练目标是详细分析，那它可能是在偏离目标。

训练目标的作用，不是直接判断每一段信息的价值，而是规定当前训练希望追求的状态、行为或效果。后续的评估、学习信号和优化方向，都需要围绕这个目标展开。

如果缺少训练目标，在进行评估时就缺少一个参照对象。面对几乎无穷的语义解释空间，我们可以描述输出发生了什么变化，却难以判断这些变化是否符合本轮训练的追求。这样一来，后续的上下文调整就容易失去统一方向性，逐渐变成对各种现象的分别响应，而不再围绕某个明确目标推进。

## 训练目标与训练过程

训练目标所关联的是整个训练过程，而不是其中某一个具体步骤。

一次训练如何组织，不只需要考虑训练所要逼近的效果，还需要考虑受训练对象当前处于什么状态、运行环境提供了哪些条件、暴露过什么问题，以及训练能够承担怎样的实现成本。这些条件共同参与训练方案的形成。

因此，即使训练目标相同，当受训练对象的当前状态、运行环境或可用材料发生变化时，实际采用的训练方式也可能不同。有时需要补充能够暴露问题的材料，有时需要调整评估方式，而有些问题则来自模型能力或运行条件，并不能仅靠修改上下文解决。

反过来，同一种训练材料、评估方式或上下文修改方法，也不只服务于某一个训练目标。它们是训练过程中可以被组织和使用的内容，其作用取决于它们在当前训练中被用来处理什么问题。

所以，训练目标与训练过程之间不是从一个目标推导出一套固定方案的对应关系。训练目标为整个训练过程提供所要逼近的效果，而具体训练方案则需要结合目标与其他训练条件共同形成。

## 训练目标与受训练对象

在上下文训练中，希望发生的变化最终表现为 Agent 系统产生了某种行为或效果，但训练过程中实际被增加、删除、重组或改写的，却是上下文信息。训练目标所描述的预期效果，与训练所直接调整的对象并不是同一种东西。

这意味着，将训练目标的描述、相关概念或案例写入上下文，只能说明受训练对象包含了这些信息，不能说明 Agent 系统已经具备相应的目标能力。这些信息进入 Agent 系统后，还需要在具体任务中被理解、选择和使用，才可能进一步转化为实际行为；这个过程同时还会受到模型能力、当前输入、运行环境和运行机制等因素影响。

因此，一段上下文经过调整后，可能使 Agent 系统更容易达成目标，也可能没有产生有效变化，甚至带来偏离、退化或其他副作用。许多浅学习现象正发生在这一层：上下文保留了概念、规则或案例的表面形式，却没有稳定形成它们所指向的行为。即使知识库成功检索出相关内容，也只是让信息进入了当前运行环境，并不保证 Agent 能够据此产生目标效果。

由此，在讨论受训练对象如何接近训练目标时，需要进一步区分一般的上下文信息，以及那些确实能够在指定条件下使目标效果发生的上下文信息。本文将在指定 Agent 系统及运行条件下，能够使系统达成某个训练目标的上下文信息称为该目标的`目标诱发上下文`。

`受训练对象`和`目标诱发上下文`描述的不是同一个维度。受训练对象描述的是一段上下文在训练过程中的身份；目标诱发上下文描述的是它相对于某个目标表现出的能力。同一段上下文可以在接受训练的同时，已经具备诱发部分目标效果的能力。

一个训练目标可以对应多份目标诱发上下文。不同的上下文内容、组织方式或信息组合，都可能使 Agent 系统达成同一个目标。因此，上下文训练不是寻找唯一正确的上下文，而是调整当前受训练对象，使它在指定条件下能够更加稳定地诱发目标效果。


## 训练目标如何形成

训练目标并不总是以同一种方式形成。

有些目标在训练开始前已经比较清楚。例如，预期效果、适用条件和目标边界已经得到充分确认的目标，或在既有训练中形成、并且仍适用于当前训练的目标。在这些情况下，训练可以直接围绕已有目标组织，不需要重新寻找目标。

另一些目标会随着训练过程继续调整。训练可能从目标 A 开始，但在运行、观察和修改过程中，发现原有目标遗漏了某种重要效果，与已有能力发生了冲突，或者训练中反复保留或放弃了一些原有目标没有涉及的效果。这时发生变化的可能是训练目标本身，也可能只是人们对目标的认识变得更准确，或者原有的目标描述得到了修正。三者并不完全相同。

还有一些训练最初只有比较宽泛的意图，尚未形成足以组织具体训练的目标。随着探索和实践不断展开，开始逐渐知道真正希望获得、保持、强化或避免的效果是什么，训练目标也在这个过程中逐渐形成。

三种情况虽然起点不同，但都属于训练目标在实践中被形成、认识或调整的过程。

因此，训练目标的形成不是从某个现象中直接得到一个答案，也不是一次性写出一句完整的目标描述，而是根据当前已经掌握的内容，不断理解这次训练真正希望达到什么效果。

从这个角度看，寻找训练目标也不是从空白开始创造一个目标。任务原本希望解决的问题、已有的目标描述、过去的训练记录、被接受或拒绝的行为、需要保持的能力，以及训练中不断出现的冲突和修正，都可能包含对训练目标的部分认识。

分析这些内容时，需要寻找的不是其中最显眼的一句话或某一个案例，而是什么预期效果能够同时解释：为什么某些行为被保留，为什么另一些行为被否定，为什么某些变化被认为是改善，以及为什么另一些变化即使看起来有效仍然不能接受。

当某种预期效果能够较稳定地解释这些已有判断，并能够继续支持当前训练时，就可以把它作为当前对训练目标的理解。后续训练仍然可能修正这种理解，但不需要等到目标完全固定后才开始训练。

## 下一步

理解了训练目标之后，我们已经知道一次训练希望逼近、保持、强化或避免什么效果。

但训练目标本身不会判断一次运行结果是否更接近目标，也不会直接把普通的输出、反馈或行为变化转化为可以用于训练的依据。
